# PetCare 디자인 스펙

이 문서는 `petcare-ui-source/` 폴더의 HTML 시안을 실제 React/Spring 프로젝트로 옮길 때
참고할 디자인 규칙입니다. 색상, 폰트, 컴포넌트 형태를 정리했습니다.

## 타이포그래피

- **로고, 큰 제목(H1), 강조 숫자**: `Jua` (Google Fonts) — 둥글고 부드러운 인상
- **본문, UI 텍스트 전체**: `Noto Sans KR`, weight 400/500/700
- 두 폰트 모두 `https://fonts.googleapis.com/css2?family=Jua&family=Noto+Sans+KR:wght@400;500;700&display=swap` 한 줄로 로드

폰트 크기 기준 (모바일):
- 페이지 제목(H1): 28px (Jua)
- 섹션 제목(H2): 17px, weight 700
- 본문: 15px
- 보조/캡션: 13px

## 형태 규칙

- **버튼**: `border-radius: 999px` (완전한 pill), 높이 48–52px, 터치 영역 최소 44px
- **카드**: `border-radius: 16px`, `border: 1px solid #E7E5E4`, `box-shadow: 0 1px 3px rgba(13,79,72,0.08)`
- **입력창**: `border-radius: 8px`, 높이 48px, `border: 1px solid #D6D3D1`
- **아이콘**: 24px, `stroke-width: 1.8`, 색 배경 원(pill) 안에 배치하는 경우가 많음 (예: 44–56px 원)
- **아이콘 스타일**: 모두 인라인 SVG, outline(선) 스타일 (이모지 사용 안 함)

## 레이아웃

- **모바일 기준 폭**: 390px. 상단 헤더 56px + 하단 탭바 76px 고정, 본문은 스크롤
- **데스크톱 기준 폭**: 1280px 프레임, 본문 콘텐츠는 1120px로 중앙 정렬 (좌우 80px 여백)
- **데스크톱 상단 네비게이션**: 높이 72px, 로고 + 가운데 메뉴 + 우측 아이콘/로그아웃

### 하단 탭바 (모바일)

- 일반 사용자(보호자): 홈 · 반려동물 · 병원 · 예약 · 마이페이지 (5개)
- 병원 소유자/관리자: 홈 · 대시보드 · 채팅 · 알림 · 마이페이지 (5개로 축소).
  반려동물/병원/예약 탭 대신 "대시보드"를 넣고, 관리자 메뉴·내 반려동물·내 예약은
  마이페이지 하위 메뉴로 옮겼습니다. (탭이 6개 이상으로 늘어나는 것을 피하기 위함)

## 상태 표시 패턴

- 예약 상태 뱃지: 대기중(amber) / 확정(green) / 거절·취소(red 계열, 거절과 취소는 색을 살짝 다르게: 거절은 `#FEE2E2`/`#B91C1C`, 취소는 중립 회색) / 노쇼(red)
- 위험도(자가문진): 낮음(green) / 주의(amber) / 높음(red) — 같은 뱃지 형태 재사용
- 빈 상태(empty state): 회색 배경 원 안에 아이콘 + 안내 문구 1줄

## 파일 구성 안내 (petcare-ui-source/)

각 파일은 **완전히 독립된 HTML**입니다 (공통 헤더/탭바를 실제 내용으로 이미 합쳐 넣었습니다).
브라우저로 그냥 열어보거나, Claude Code에 "이 파일들 구조를 참고해서 컴포넌트로 만들어줘"
라고 시키면 됩니다. 파일명은 문서에서 설명한 화면 경로와 대응됩니다 (예: `Main.html` → `/`,
`PetList.html` → `/pets`, `HospitalDetail.html` → `/hospitals/:id`).

실제 프로젝트에서는 헤더/탭바/네비게이션을 공통 컴포넌트로 다시 분리해서 쓰면 됩니다 —
여기서는 참고 편의를 위해 화면마다 내용을 풀어서 넣었습니다.
